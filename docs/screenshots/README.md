## Taking them

Full-window captures at a normal desktop width read best in the README's
two-column tables — roughly 1600px wide, PNG. Keep them under about 500KB each
so a clone stays small; a screenshot that large is usually worth passing
through an optimiser.

Sign in with a real account and use data that already exists rather than
staging anything: these are documentation of the product, so a screenshot that
shows a state the product cannot actually reach is worse than no screenshot.

Avoid capturing anything you would not publish — real learner names and email
addresses appear on the admin tables, and this repository's README is the most
public surface in it.
